# Таймеры — Cloudflare Worker + D1

Архитектура: браузер → Cloudflare Worker → Cloudflare D1.
Фронтенд (папка `public/`) раздаётся тем же Worker'ом как статика.

## Структура

```
timers-app/
├── wrangler.toml       # конфиг Worker'а и биндинг D1
├── schema.sql          # схема базы данных
├── src/worker.js        # backend: авторизация, API таймеров и пользователей
└── public/              # frontend
    ├── index.html
    ├── style.css
    └── app.js
```

## 1. Публикация на GitHub

```bash
cd timers-app
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
git push -u origin main
```

## 2. Установка инструментов Cloudflare

```bash
npm install -g wrangler
wrangler login
```

## 3. Создание базы данных D1

```bash
wrangler d1 create timers-db
```

Команда выведет `database_id` — скопируйте его в `wrangler.toml`, заменив
`REPLACE_WITH_YOUR_DATABASE_ID`.

## 4. Применение схемы

```bash
wrangler d1 execute timers-db --remote --file=./schema.sql
```

## 5. Деплой Worker'а

```bash
wrangler deploy
```

Wrangler выдаст адрес вида `https://timers-app.<ваш-поддомен>.workers.dev`.

## 6. Создание первого администратора

Откройте сайт — на экране входа будет ссылка «Создать первого администратора».
Она сработает только один раз, пока в базе нет ни одного пользователя.

После этого администратор может заходить в раздел «Пользователи» и:
- добавлять новых пользователей с паролем и ролью (`user` / `admin`);
- менять пароли существующим пользователям;
- удалять пользователей.

## Как это устроено

- **Пароли**: хранится SHA-256(соль + пароль) и сама соль, пароли открытым
  текстом нигде не хранятся.
- **Сессии**: после входа выдаётся cookie `session` (HttpOnly, Secure,
  30 дней), токен сессии живёт в таблице `sessions` в D1.
- **Доступ**: любой залогиненный пользователь видит и может создавать/
  редактировать таймеры; управление пользователями доступно только роли
  `admin`.
- **Таймеры**: хранятся в таблице `timers` — название, описание (что именно
  отсчитывается) и целевая дата/время. Таймеров можно создавать сколько угодно.
